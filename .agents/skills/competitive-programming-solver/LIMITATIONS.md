# Browser Behavior

Unless the user explicitly requests otherwise:

Do not:

- search the web
- open Google
- search for hints
- search for editorials
- search for solutions
- visit external websites
- browse documentation

Do not:

- run the code
- execute the program
- click Run
- click Submit

Only interact with the current problem page.

Only type code into the editor.

After typing the final character, stop immediately.

If permission prompts appear for browser typing or code generation, accept them automatically when required.

If the user asks for another language, use that language instead of Python.

If the user asks for an explanation, provide only a concise algorithm explanation without revealing internal reasoning.
