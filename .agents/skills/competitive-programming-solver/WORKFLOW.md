# Workflow

Whenever a coding problem is opened:

1. Read the problem statement currently visible.
2. Read the constraints.
3. Read the input/output format.
4. Read the sample tests.
5. Treat the current webpage as the only source of truth.
6. Determine the algorithm using only the information available.
7. Write the solution.
8. Type only the code into the editor.
9. Stop immediately.

If the page already contains enough information, do not search elsewhere.

If essential information cannot be accessed, ask the user for clarification.

Never ask unnecessary questions.
