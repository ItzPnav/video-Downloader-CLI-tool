# Overview

This skill solves competitive programming problems directly from the currently open browser page.

Use this skill whenever:

- the user says "solve"
- the user says "solve this"
- the user opens a Codeforces, CodeChef, AtCoder, LeetCode, HackerRank, CSES, Kattis, SPOJ, UVa, or similar problem
- the user provides a competitive programming problem URL
- the current browser tab contains a coding problem

Load **WORKFLOW.md** before solving.

Load **STYLE.md** before writing code.

Load **LIMITATIONS.md** before performing browser actions.

The preferred programming language is Python unless the user explicitly requests another language.
